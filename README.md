# 🇮🇳 India Superstore Customer Behavior Analysis (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a retail dataset adapted to the Indian market. The original dataset was transformed by converting all monetary values from USD to INR, making the analysis more realistic and relevant.

The goal of this project is to analyze sales performance, customer behavior, and business trends to generate meaningful insights for better decision-making.

---

## 🎯 Objectives

* Analyze overall sales and profit performance
* Identify top-performing categories and sub-categories
* Understand customer segmentation and contribution
* Examine regional and city-wise sales trends
* Study the impact of discounts on profitability

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Plotly / Dash (for dashboard)

---

## 📊 Key Features

* KPI metrics (Total Sales, Profit, Orders, Discount)
* Category-wise Sales & Profit Analysis
* Monthly and Yearly Sales Trends
* Regional Performance (States & Cities)
* Customer Segmentation Analysis
* Top Customers by Revenue
* Discount vs Profit Relationship

---

## 🔍 Key Insights

* Technology category generates the highest profit
* Sales peak during year-end months (Q4 growth)
* Higher discounts lead to lower or negative profit
* A small group of customers contributes significantly to revenue
* West and East regions dominate overall sales performance

---

## 📁 Dataset

* Source: Superstore Dataset
* Modified for Indian context:

  * Currency converted from USD → INR
  * Locations adapted to Indian regions

---

## 🚀 How to Run

1. Clone this repository
2. Install required libraries:

   ```bash
   pip install pandas matplotlib seaborn plotly dash
   ```
3. Run the Python script:

   ```bash
   python eda.py
   ```
4. Open dashboard in browser (if using Dash)
